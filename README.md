# 微信待办备忘录与定时预警提醒小程序 (Reminder Mini-Program)

一个专为个人及亲友小圈子设计的极简、高效微信待办备忘小程序。支持每日晨报待办汇总推送、每个待办独立设置截止时间（DDL）及个性化提前预警提醒，消息通过微信公众号模板消息直达微信聊天列表。

---

## 💡 为什么选择这个方案？

- **微信生态闭环**：无需额外安装独立 App，微信内随时记录、随时查看。
- **免服务器零运维**：基于微信小程序官方**云开发（CloudBase）**，自带数据库与 Serverless 云函数，无需购买云主机或配置域名备案。
- **消息 100% 稳定必达**：微信官方对个人开发者未开放小程序端长期订阅消息配额（一次性订阅消息需每次手动授权）。本项目后端集成 **PushPlus（推送加）** 微信公众号通道，用户只需关注公众号并绑定 Token，即可在微信中接收富文本 Markdown 排版的待办卡片。

---

## 🌟 核心功能

1. **待办事项全生命周期管理**：
   - 标题、详细备注输入与字段校验。
   - 截止日期与时刻（支持跨天、跨月精确到分钟）选择。
   - 待办状态一键勾选完成、长按菜单编辑与删除。
2. **个性化 DDL 提前提醒**：
   - 每项待办支持单独设置预警档位：**准时提醒、提前 15 分钟、提前 30 分钟、提前 1 小时、提前 2 小时、提前 1 天**。
   - 云函数自动换算毫秒级绝对预警时间戳 `target_remind_time`。
   - 每 5 分钟自动执行 DDL 巡检，命中后推送卡片并标记防重发。
3. **每日晨报定时汇总**：
   - 每天早晨定时触发（默认 `08:30`，支持用户自定义时间与开关）。
   - 智能归集：逾期未完成事项、今日必做事项、后续待办概览。
   - 格式化输出清爽易读的 Markdown 微信卡片。
4. **可视化数据看板与分类**：
   - 顶部统计：待办总数、今日必做数、已逾期数。
   - 快速 Tab 过滤：今日必做、全部待办、已完成。
5. **用户设置与一键连通性测试**：
   - 录入 PushPlus Token 后支持一键发送测试消息，秒级验证推送是否正常。
   - 晨报开关与时间自定义保存。

## 🚀 快速上手与部署指引

### 第一步：获取 PushPlus Token（约 1 分钟）
1. 微信搜索公众号 **pushplus推送加**（或访问 [pushplus.plus](https://www.pushplus.plus)）并关注。
2. 进入公众号菜单或官网登录，在【一对一推送】中复制你的 **Token**（例如 `a1b2c3d4...`）。

### 第二步：导入微信开发者工具
1. 打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 点击 **导入项目**：
   - **项目目录**：选择本项目根目录。
   - **AppID**：填入你自己的微信小程序 AppID（测试号可能无法开通云开发，建议使用个人注册的小程序 AppID）。
   - **后端服务**：选择 **微信云开发**。

### 第三步：开通并初始化云开发环境
1. 在微信开发者工具顶部工具栏，点击 **云开发** 图标开通云环境。
2. 记下你的 **环境 ID**（例如 `cloud1-xxxxxx`）。
3. 打开根目录下的 `app.js`，将 `env: "your-env-id"` 替换为你的真实云开发环境 ID：
   ```javascript
   // app.js
   wx.cloud.init({
     env: "你的环境ID",
     traceUser: true,
   });
   ```

### 第四步：创建云数据库集合
在云开发控制台的【数据库】中，点击“+”添加两个集合：
1. `todos`：用于存储待办事项（权限推荐：**仅创建者可读写**）。
2. `users`：用于存储用户设置（PushPlus Token、晨报偏好等，权限推荐：**仅创建者可读写**）。

### 第五步：上传并部署云函数与定时器
在微信开发者工具的项目文件树中，右键点击 `cloudfunctions/` 下的各个目录：
1. 右键 `todoApi` -> **创建并部署：所有文件**。
2. 右键 `userApi` -> **创建并部署：所有文件**。
3. 右键 `cronDailyMorning` -> **创建并部署：所有文件**，随后右键点击该目录下的 `config.json` -> **上传触发器**。
4. 右键 `cronCheckDdl` -> **创建并部署：所有文件**，随后右键点击该目录下的 `config.json` -> **上传触发器**。

> **提示**：云函数运行环境基于 Node.js 16/18，云端会自动根据 `package.json` 安装依赖。

### 第六步：在小程序中完成绑定
1. 在开发者工具中点击 **编译** 运行小程序。
2. 点击首页右上角 ⚙️ **设置** 按钮。
3. 粘贴你的 **PushPlus Token**，点击 **一键测试推送**。
4. 微信若收到“🎉 恭喜！PushPlus 推送连接成功”服务通知，即代表全部配置完毕！

## 🧪 自动化测试套件

本项目附带完整的单元测试与全生命周期端到端（E2E）测试脚本，在免部署环境下可直接使用 Node.js 离线验证业务逻辑：

```bash
# 验证脚手架配置
node tests/test_scaffold.js

# 验证待办增删改查与提前提醒算法
node tests/test_todoApi.js

# 验证用户配置与推送参数校验
node tests/test_userApi.js

# 验证晨报分组与 Markdown 模板渲染
node tests/test_cronDailyMorning.js

# 验证 DDL 临期巡检过滤算法与防重发机制
node tests/test_cronCheckDdl.js

# 运行全链路端到端闭环测试
node tests/e2e_smoke.js
```
